# 界面千绘莉化：GPT Image 提示词

主题：**打烊后的咖啡馆 · 俄罗斯蓝猫前辈**。底色用她连衣裙的藏青、头发的银灰，卡片用奶油色，点缀用耳朵里的樱粉和眼睛的蓝紫；小装饰是猫耳、肉球、尾巴、黑樱桃发夹、白缎带、咖啡和蛋糕。

## 怎么用

- 每个代码块都是一条完整的提示词（画风和角色描述已经写在里面），整块复制给 GPT Image 就行。
- **画到角色的图（2、3、4、5、9 号）请同时上传 `1.png`（全身）和 `build/icon.png`（脸）当参考图**，否则长相会跑偏。几张 Q 版贴纸最好在同一个对话里连着生成，画风更统一。
- 透明背景：请它输出透明背景的 PNG。如果做不到透明，就改成「solid pure green #00FF00 background」，抠图我来做。
- 图里**不要有文字**：名字可以在设置里改，而且画出来的汉字常有错字。标题文字、按钮仍然用代码画。
- 尺寸按下表生成就行（GPT Image 的方图 / 横图 / 竖图），裁剪、缩放、转格式都由我来做。
- 生成好后，按「文件名」那一栏的名字放进 `art/` 文件夹，告诉我，我来接进界面。颜色、按钮、边框和那套线条图标我直接改代码（换成带猫耳、肉球的版本），不需要生成。
