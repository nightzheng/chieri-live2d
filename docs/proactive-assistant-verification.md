# 千绘莉 1.2.9 实现与验证

版本基于 `feat/persistent-memory` 的 1.2.8 提交。应用身份、NSIS 安装身份、配置目录、默认 SQLite 路径、用户指定的 SQLite 位置、原对话 API 和已有语音配置沿用 1.2.8。

## 数据和行为

| 模块 | 位置与行为 |
|---|---|
| SQLite schema 2 | 在事务中创建 `reminders`、`reminder_events` 和 `proactive`。提醒、执行状态和主动互动的偏好、下次发言时间、发言配额随完整库迁移和备份。提醒的可移植 JSON 只保存定义，导入时暂停 |
| 日程提醒 | 日期和时间使用创建时选择的时区。重复提醒按当地时间计算。夏令时缺失的时间顺延，重复的时间采用第一次。睡眠和退出期间的多次错过合并为每项提醒一条待处理记录。事务先记录本次执行，再显示通知或气泡 |
| 主动互动 | 默认关闭。主进程按频率、安静时段、每日额度和互动后的三分钟冷却调度。录制模式暂停闲聊。渲染窗口复用现有气泡和语音队列。聊天和提醒优先，进行中的闲聊可被提醒或用户操作打断。AI 闲聊不读取聊天原文，也只有在两处记忆开关均允许时使用已保存的部分兴趣、偏好或事项 |
| 视觉配置 | `%APPDATA%\千绘莉\vision-settings.json` 保存独立服务地址、模型、图像大小和质量及超时。视觉密钥在主进程用 Electron `safeStorage` 加密。视觉模型设置独立于聊天设置 |
| 视觉授权 | Windows 主进程先枚举名称。用户选定来源后，Electron 桌面捕获接口可能在进程内生成同类型来源的缩略图，千绘莉只保留选定的一张供预览，向服务发送的就是该预览。应用自己的窗口在捕获时请求 Windows 排除。预览两分钟失效，单次确认只能消费一次。每次发图最多 1 MB，间隔至少 30 秒 |
| 限时观察 | 每次显式授权，最长 30 分钟，只对选定来源按固定周期重新截图。状态指示和托盘提供停止入口。随停止、锁屏、休眠、隐藏、关闭、来源变化、请求失败或到期结束，已等待的请求会被取消。会话不会跨重启恢复 |
| 视觉隐私 | 截图和最近分析由应用保存在内存，默认不写入文件、SQLite 或日志。远程服务收到请求后遵循其自身的数据政策。发送分析文字给聊天模型、通过语音引擎朗读或保存到长期记忆需要分别确认。模型输出作为文本显示，截图里的指令没有桌面操作权限 |

Windows 的窗口排除能力和生效时机参见 [Electron BrowserWindow 文档](https://www.electronjs.org/docs/latest/api/browser-window/#winsetcontentprotectionenable-macos-windows)。每次分享前仍应检查画面中是否有敏感信息。

## 复测命令

```powershell
npm test
node tests/migration-compat.cjs d1d3d5d
.\node_modules\.bin\electron.cmd tests/assistant-smoke.cjs
$env:CHIERI_TEST_PYTHON = 'D:\miniconda\envs\Chieri\python.exe'
node tests/voice-lifecycle.cjs
.\node_modules\.bin\electron.cmd tests/electron-smoke.cjs
npm run dist:lite
npm run dist
```

22 项单元测试通过。桌面测试使用隔离配置和合成用户数据。视觉测试在 Windows Electron 中使用合成画面、模拟确认、锁屏事件和本地服务，避免捕获当前用户的真实桌面。普通聊天使用模拟服务。GPU 回归使用现有 Conda 环境和原权重的副本。完整版构建前需准备 README 指定的模型文件。
