# 千绘莉 1.3.0 验证报告

## 记忆和陪伴

1.2.9 已有候选确认、偏好覆盖、存储迁移、备份和启停开关。检索逐行扫描，有限的字面匹配容易漏掉中文同义表达。记忆没有有效期和重要性，主动闲聊使用固定随机范围，未区分看见后回应和连续未回应。

- 本地规则保留明确保存请求，跳过识别到的玩笑、假设、敏感信息和普通临时安排。明确保存的临时事实会显示有效期。可在设置中手动更正、修改期限或编辑归档条目。归档内容保留；不会按使用时间删除。
- AI 辅助发送聊天中最多三条、每条最多 300 字的近期用户原文，过滤已识别的敏感内容，不使用助手回复、视觉结果或触摸事件。请求最多每十分钟一次、每 24 小时六次，失败也计入限额。证据必须引用实际用户原文并与候选内容有词项交集，仍需用户确认。证据检查无法证明所有候选语义准确，本地敏感词过滤也不能识别所有私人信息。
- SQLite schema 3 添加重要性、有效期和中文词项索引。检索组合有限的同义词表、二/三字词项、命中频率、确认置信度、重要性和更新时间。超过有效期的事实归档，日期明确的历史事件仍可检索。界面可查看最近实际选入请求的条目与匹配词。
- 陪伴状态使用现有提醒与闲聊调度。录制、锁定、专注、安静、忙碌和待发提醒都优先于普通闲聊。发言后五分钟内有聊天回应会清除忽略计数，两次未回应后延长间隔。设置中的手动安静或专注会持久化，聊天命令的临时状态和忽略计数在重启后重新开始。仅使用千绘莉内的交互时间，不需视觉授权。
- 新版本在迁移前用 `VACUUM INTO` 创建并验证 `before-schema-2-to-3-*.sqlite`，然后事务更新原库。默认和自定义位置均为原路径。1.2.9 拒绝 schema 3，若需回退，用升级前的快照恢复；升级后的新增数据需要另备。

### 1.3.2 设置页回归

设置区域沿用原有字体，统一了日期、时间、提示、折叠项和数据列表的字号与行距。低高度时压缩标题、导航和底部按钮。分类导航高亮当前区域，可用键盘访问开关。

运行 `tests/settings-ui-smoke.cjs`，通过 `CHIERI_SETTINGS_MODE` 分别选择 `studio`、`pet` 和 `web`。Windows Electron 核对了主窗口、最小比例桌宠窗口、无桌面接口的窄网页布局。测试覆盖字体声明、横向截断、分类导航和候选提示。用合成对话验证了取消候选后长期库无记录，确认后才入库。外部浏览器和其他系统字体组合未逐一实测。

### 固定为 1.2.8 的设置更新

同一套 Windows Electron 测试覆盖底部统一保存、关闭时保留或放弃草稿、显示已存的视觉密钥、手动滚动高亮，以及日常语气词的关闭和间隔。语气词设置会抑制自动发声，保留表情和动作。新安装包固定显示 1.2.8，数据库仍使用 schema 3，安装目录识别沿用原地覆盖修复。此次未在实际用户配置上运行覆盖安装。

### 1.2.8 主动观察与按钮反馈

- `npm test` 28 项通过。虚拟时钟用例验证授权和计时器本身均不上传，符合对话次数时才请求视觉服务，以及会话结束后停止采样。
